# MockLab — Fake Post Generator

Create pixel-perfect social media mockups for 17+ platforms. Edit every detail on the left, see the live preview on the right, and download as PNG.

## Supported Platforms

**Social Posts:** X (Twitter), LinkedIn, Instagram Post, Instagram Story, Reddit, Facebook, Threads, YouTube Comment, TikTok Comment

**Chat Messages:** WhatsApp, WhatsApp Group, Instagram DM, Telegram, Slack, Discord, iMessage

**Email:** Gmail

## Tech Stack

- **Next.js 16** with App Router & Turbopack
- **Tailwind CSS v4** + **shadcn/ui**
- **motion/react** for micro-animations
- **html-to-image** for PNG export
- **Geist** font family

## Getting Started

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000).

## Features

- Live preview with pixel-perfect mockups
- Full configurability (verified badges, reactions, timestamps, read receipts, etc.)
- Download as high-resolution PNG (2x pixel ratio)
- Smooth platform switching animations
- Dark mode UI
- Chat message editor (add/remove/edit messages)
